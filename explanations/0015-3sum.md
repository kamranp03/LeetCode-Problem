# Problem 0015 - 3Sum

**Difficulty:** Medium
**LeetCode:** https://leetcode.com/problems/3sum/
**Language:** C++

---

## Problem Statement

Given an integer array `nums`, return all unique triplets `[nums[i], nums[j], nums[k]]` such that `i != j != k` and `nums[i] + nums[j] + nums[k] == 0`. The solution set must not contain duplicate triplets.

## Approach: Sort + Two Pointers

The key insight is that after sorting the array, we can fix one element `nums[i]` and reduce the problem to finding two numbers in the remaining sorted subarray that sum to `-nums[i]`. Two pointers on this subarray let us find all such pairs in O(n) per fixed element, and we skip duplicates at both the outer and inner levels to guarantee unique triplets.

## Code Walkthrough (Step by Step)

1. **Sort** `nums` — this enables two-pointer and duplicate skipping.
2. **Outer loop** over `i` from `0` to `n-3`:
   - **Skip duplicates:** if `i > 0` and `nums[i] == nums[i-1]`, continue.
   - Set `left = i+1`, `right = n-1`, and `sum = -nums[i]` (what left+right must equal).
3. **Inner two-pointer loop** while `left < right`:
   - Compute `s = nums[left] + nums[right]`.
   - If `s == sum`: found a triplet! Push `{nums[i], nums[left], nums[right]}`, then move both pointers and skip duplicates on both sides.
   - If `s > sum`: `right--` (need a smaller value).
   - If `s < sum`: `left++` (need a larger value).
4. **Return `res`.**

## Dry Run

**Example Input:** `nums = [-1, 0, 1, 2, -1, -4]`

After sorting: `[-4, -1, -1, 0, 1, 2]`

| i | nums[i] | target sum | left | right | nums[l]+nums[r] | Action |
|---|---------|-----------|------|-------|-----------------|--------|
| 0 | -4      | 4         | 1    | 5     | -1+2=1          | left++ |
| 0 | -4      | 4         | 2    | 5     | -1+2=1          | left++ |
| 0 | -4      | 4         | 3    | 5     | 0+2=2           | left++ |
| 0 | -4      | 4         | 4    | 5     | 1+2=3           | left++ |
| 1 | -1      | 1         | 2    | 5     | -1+2=1 = sum    | push [-1,-1,2], skip dups |
| 1 | -1      | 1         | 3    | 4     | 0+1=1 = sum     | push [-1,0,1] |
| 2 | -1      | skip (dup)| —    | —     | —               | — |
| 3 | 0       | 0         | 4    | 5     | 1+2=3           | right-- |
| ... | ...   | ...       | ...  | ...   | no match        | — |

**Output:** `[[-1,-1,2],[-1,0,1]]`

## Complexity Analysis

| | Complexity | Reason |
|--|--|--|
| **Time** | O(n²) | O(n log n) for sort + O(n) two-pointer scan for each of n elements |
| **Space** | O(1) | No extra space beyond the output (sort is in-place) |
